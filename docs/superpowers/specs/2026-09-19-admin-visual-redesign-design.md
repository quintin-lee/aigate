# 管理后台视觉重设计（admin.html）设计文档

- 日期：2026-09-19
- 范围：`web/admin.html`（单文件，当前 1657 行）4 个区域
- 状态：4 节设计均已由用户确认（A/A/A/A）

## 1. 背景与目标

管理后台历经中文汉化、无 Tailwind 兜底、P0+P2 交互优化三轮，已无功能缺口。
本轮目标是统一视觉语言：深色高级感、一致的圆角/间距/配色体系，
各页面元素（导航、卡片、表格、调试场、弹窗）用同一套 token。

## 2. 全局约束（已确认假设）

1. 保持单文件 `web/admin.html`，不拆分 CSS/JS 文件。
2. 保留 Tailwind CDN；已有无 CDN 兜底（#mainNav/#mobileNav 媒体查询）不得破坏。
3. 中文文案、6 个页面结构、全部数据接口与 JS 逻辑不变，只动样式层。
4. 不新增浅色主题（本次不做双主题）。

## 3. 设计⠀⠀（4 节）

### 第 1 节：导航形态 + 配色基调 —— A·全深色 ✅

- 顶部导航改为左侧固定侧边栏：AI 网关标题 + 6 入口（总览/模型/API 密钥/用量/调试场/监控指标）。
- 顶部保留瘦顶栏：页面标题 + 连接徽标（三态）+ 刷新按钮。
- 色板：侧边栏 `#0f172a`，内容区 `#1e293b`，卡片 `#0f172a` 配 `1px #334155` 边框，
  主色靛蓝 `#6366f1`，成功绿 `#22c55e`，危险红 `#ef4444`，文字 `#f1f5f9/#94a3b8`。
- 移动端：侧边栏收起为汉堡菜单，复用现有 `#mobileNav` 逻辑，只换皮肤。

### 第 2 节：总览页 —— A·图标卡 ✅

- 统计卡：左 38px 图标色块（各指标不同底色（靛 `#6366f1`/绿 `#22c55e`/琥珀 `#f59e0b`/蓝 `#3b82f6`，15% 透明底））+ 右侧标签与数值。
- 图表卡：靛蓝 `#6366f1` 渐变面积图 + 细网格线，卡片圆角 12px。
- 快捷操作区改为图标按钮组，与统计卡同高对齐。
- 不做趋势卡（B 方案需昨日对比数据，本次不碰接口）。

### 第 3 节：数据表格页 —— A·宽松 ✅

- 行高 52px；sticky 表头（`#0f172a` 底）；行 hover 高亮 `#1e293b`。
- 状态徽标描边化：启用=绿描边胶囊，停用=灰描边胶囊。
- 筛选栏胶囊化（圆角 99px 输入/下拉），与表格卡片同宽对齐。
- 空状态：居中文字 + 引导按钮（如“去创建模型”）。
- 加载占位行（P0 已落地）换肤为新徽标色，行为不变。

### 第 4 节：调试场 + 弹窗 —— A·聊天气泡 ✅

- 对话区：用户消息右对齐靛蓝实心气泡（右下小圆角），助手消息左对齐深灰描边气泡。
- 表单控件（模型选择/温度/输入框）与筛选栏同款胶囊/圆角。
- 5 个弹窗统一：16px 圆角 + 半透明遮罩 + 主按钮靛蓝实心、次按钮描边；
  确认弹窗（#confirmModal，P0 已落地）同步换肤；ESC 关闭行为不变。

## 4. 验收标准

1. `node --check`（双内联脚本提取）通过；页面可正常打开，各 Tab 切换正常。
2. 无 Tailwind CDN 时侧边栏/移动菜单仍正确显示（回归第 0558b8f 条修复）。
3. 有 / 无数据、加载中、接口失败三态样式齐全，无裸英文、无错位。
4. 桌面 1440px 与移动 375px 各截一屏对照，符合第 1～4 节 mockup。

## 5. 不做事项（YAGNI）

- 浅色主题 / 主题切换；趋势卡环比数据；图表库替换（仍用现有实现）；
- 移动端导航高亮、autoFill 落实等上一轮 P1 遗留项不在本轮范围。
